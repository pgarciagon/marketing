# Brand

This area maintains the shared external narrative and points contributors to the current official visual system.

## Files

- [Message house](message-house.md) — the core narrative, proof points, audience adaptations, terminology, and claims to avoid.

## Visual identity

Use the current [official Koinos media kit](https://koinos.io/media) as the source of truth for logos, clearspace, colors, and downloadable assets.

At the time this index was prepared, the published palette was:

| Role | Value |
| --- | --- |
| Koinos Purple | `#5d00b3` |
| Accent Purple | `#9966FF` |
| Koinos Black | `#121212` |
| White | `#FFFFFF` |

Verify the live media kit before creating a major or long-lived asset. Do not redraw, distort, recolor, crop, or add effects to the Koinos mark unless the current guidelines explicitly permit it.

## Asset classes

- **Official brand assets:** obtained from the media kit and used according to its rules.
- **Campaign assets:** created for a specific brief and stored with that campaign or in `images/`.
- **Historical evidence:** screenshots and artwork preserved for documentary context; these are not automatically current brand assets.
- **Community creations:** clearly credited and never presented as official without approval.
