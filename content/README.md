# Content

This area coordinates reusable editorial material and keeps the status of drafts and published work explicit.

## Content types

- Announcements and release notes.
- Technical explainers and tutorials.
- Ecosystem and contributor stories.
- Case studies and demonstrations.
- Press backgrounders and media pitches.
- Social posts and discussion prompts.
- Video briefs, scripts, and captions.
- Translations and localized adaptations.
- Corrections and incident communication.

## Required metadata

Add this block near the top of a new content document:

```text
Status:
Owner:
Audience:
Channel:
Source language:
Source document:
Last fact check:
Approval owner:
Published URL:
```

## Editorial rules

- Start with the audience’s question or problem.
- Use the [message house](../brand/message-house.md) selectively; do not force every pillar into one piece.
- Separate claims about current software from roadmap or experimental work.
- Link technical claims to primary evidence.
- Make calls to action specific and feasible.
- Give images useful alt text and verify usage rights.
- Preserve a clean source edition for translations.
- After publication, confirm the live result before changing status to `published`.
