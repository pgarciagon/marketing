# koinos_marketing

`koinos_marketing` is a community coordination center for Koinos communication, branding, research, campaigns, and reusable publishing material.

The repository exists to help contributors coordinate work, take accountable action, and communicate a consistent, evidence-based message to people outside the existing Koinos community.

## Operating model

```text
evidence -> brief -> draft -> review -> approval -> publication -> verification -> learning
```

1. **Start with evidence.** Separate confirmed facts, interpretation, and proposals.
2. **Open a brief.** Define one audience, objective, owner, channel, and measurable outcome.
3. **Create the material.** Reuse the message house and official visual system.
4. **Review it.** Check factual accuracy, tone, brand consistency, links, and risk.
5. **Approve publication.** Repository approval does not automatically authorize a person to post from an official account.
6. **Verify the live result.** Record the final URL and confirm the published material is complete.
7. **Learn.** Add results and decisions so the next campaign starts with better information.

## Source hierarchy

Use the narrowest authoritative source available for each claim:

1. Current official Koinos website, documentation, repositories, releases, and on-chain records.
2. Approved project or foundation statements.
3. Direct statements from an identified contributor about their own work.
4. Independent reporting and archived public evidence.
5. Community discussion, clearly labeled and corroborated before publication.

Historical handoffs and dated snapshots provide context, not proof of current external state.

## Collaboration boundaries

- Do not store passwords, private keys, API tokens, private messages, unpublished personal information, or precise private contact details.
- Do not imply that a contributor speaks officially for Koinos unless that authority has been confirmed.
- Drafting and review do not authorize publication, spending, account access, or outreach.
- Do not coordinate artificial engagement, undisclosed sponsored coverage, spam, or misleading market claims.
- Treat price, liquidity, token contracts, exchange availability, roadmap status, team roles, and live network statistics as time-sensitive.
- Preserve original evidence and distinguish it from interpretation.
